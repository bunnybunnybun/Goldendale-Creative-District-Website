# Goldendale Creative District Website
It's a website, wow so cool.
This is the website for the Goldendale Creative District, a super cool organization that runs community art related events :P

It's written in plain HTML + CSS for those curious, I guess.  It took a surprising amount of time for how basic of a website it is, so I hope you like it 😺

You can view the site live at [goldendalecreativedistrict.org](https://goldendalecreativedistrict.org).
